# Entrega 086 - Resultados de comandos no painel

## Entregue

- O historico do dispositivo agora apresenta o nome legivel de cada comando e ate seis execucoes recentes.
- Comandos concluidos possuem resultado recolhivel no painel.
- Falhas exibem o erro retornado pelo agente no mesmo local.
- Saidas longas, como processos e servicos, ficam limitadas por uma area rolavel e nao expandem o layout inteiro.

## Limite

O painel ainda nao possui filtros, exportacao ou uma tela dedicada para resultados historicos. A fila continua sendo o mecanismo operacional atual.
