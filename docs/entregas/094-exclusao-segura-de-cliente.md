# Entrega 094 - Exclusao segura de cliente

## Entregue

- A exclusao de cliente agora considera computadores ativos e arquivados.
- O painel continua bloqueando a operacao enquanto houver dispositivos ou chaves vinculadas.
- Isso evita que um cliente com computador arquivado passe pela validacao e falhe depois por restricao de relacao no banco.
