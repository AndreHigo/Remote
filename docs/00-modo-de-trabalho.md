# Modo de trabalho

Este projeto deve evoluir em entregas pequenas, verificaveis e sempre com clareza do que falta.

## Padrao de cada entrega

Toda etapa deve responder:

1. O que foi entregue.
2. Como foi validado.
3. O que ainda falta.
4. Qual e o proximo passo recomendado.

## Regra pratica

Nao encerrar uma fase apenas com ideia ou promessa. Mesmo quando a entrega for pequena, ela precisa deixar algum artefato real:

- documento;
- diagrama;
- tela;
- endpoint;
- script;
- configuracao;
- teste;
- prototipo funcional.

## Formato de fechamento

```text
Entregue:
- ...

Validado:
- ...

Falta:
- ...

Proximo passo:
- ...
```
