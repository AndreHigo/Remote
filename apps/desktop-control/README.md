# Desktop Control

Aplicativo desktop futuro para tecnicos.

Responsabilidades:

- abrir sessoes remotas com parametros seguros;
- integrar com o painel web;
- manter experiencia mais nativa no Windows;
- futuramente embutir motor proprio ou cliente remoto customizado.

Stack candidata:

- Tauri;
- React;
- Rust para integracoes locais.
