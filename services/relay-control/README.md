# Relay Control

Camada de integracao com servidores de ID, sinalizacao e relay.

No MVP, pode controlar e documentar servidores RustDesk OSS. No futuro, pode evoluir para relay proprio ou integracao mais profunda.

Responsabilidades:

- registrar endpoints de relay;
- acompanhar saude e uso de banda;
- gerar configuracao de agente/cliente;
- separar infraestrutura por ambiente;
- apoiar futura oferta on-premise.
